# Coffee Shop Sales Analysis Warm-Up

## Scenario
You are a junior data analyst working for a regional coffee chain.

Management wants to understand:
- Which store performs the best
- Which product categories are the most profitable
- Whether discounts are negatively affecting profits
- What improvements should be made next month

---

## Level 1 — Explore the Data

Answer the following questions:

- How many rows and columns are in the dataset?
- What data type should each column use?
- Are there any potential data quality or business concerns?

---

## Level 2 — Business Questions

Use the dataset to answer the following:

- Which store generated the most revenue?
- Which category generated the highest profit?
- Which product sold the most units? - expresso
- Did stores offering discounts appear more profitable? - no
- Which region would you recommend investing more money into? - East/south

### Required Calculations

Create calculations for:

- Profit
- Profit Margin

---

## Level 3 — Visualization

Think like a business analyst:

- What chart would best display revenue by store? - bar
- What chart would best show category profitability? - bar/column
- What slicers or filters would improve the dashboard experience? region/product/category/date
